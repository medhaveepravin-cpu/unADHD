How it works

Dump your intents

Add what needs doing and where each one lives (an app or a link).

Wander freely

The card floats along with you, showing just the current one.

Finish, then next

One tap takes you back to it. Mark it done and the next appears.

Download

Free, open source, and fully on-device — no account, no sync, no tracking.

↓ Download unADHD.zip
First launch (one time): unADHD isn't notarized yet, so macOS will warn that it's from an unidentified developer. To open it:
  1. Unzip unADHD.zip and move unADHD.app to your Applications folder.
  2. Right-click the app → Open → Open in the dialog.
  3. If macOS still blocks it: System Settings ▸ Privacy & Security ▸ scroll down ▸ Open Anyway.
Prefer to build it yourself? Build from source — it compiles with the Command Line Tools, no Xcode needed.
