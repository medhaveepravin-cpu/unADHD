Private by design

What it can and can't see

unADHD asks for as little as possible — so no permission prompt should ever look suspicious.

100% on-device

No account, no sync, no servers, no analytics — unADHD makes no network calls at all.

No Accessibility or Automation access

It sees which app is frontmost using macOS's standard app-switch notifications — it never reads or controls your other apps.

The ⌃⌥⇧U shortcut needs no special access

It uses a system hotkey API, so there's no Accessibility prompt to approve.

Asked only if you opt in

Notifications — only when you turn on nudge notifications. A Login Item — only if you enable “Launch at login.” That's it.

Read this first — first launch (one time)
unADHD isn't notarized yet, so macOS will warn that it's from an unidentified developer and may say it "cannot verify it's free of malware." That's expected for an unsigned open-source app — here's the fix:
  1. Unzip unADHD.zip and move unADHD.app to your Applications folder.
  2. Open Terminal and run this — it clears the "downloaded from the internet" flag on just this app, then double-click to open:
    xattr -dr com.apple.quarantine /Applications/unADHD.app
  3. Prefer no Terminal? Double-click the app, dismiss the warning, then go to System Settings ▸ Privacy & Security ▸ scroll down ▸ Open Anyway.

Only run that command on apps you downloaded from a source you trust (like this page). It doesn't disable any system protection — it just skips the check for this one file. On macOS 15+ the old right-click → Open shortcut no longer works.

Prefer to build it yourself? Build from source — it compiles with the Command Line Tools, no Xcode needed.
